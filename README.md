# myHelper — трекер «что я делаю»

Бот раз в час спрашивает «Что делаешь? Что делала в течение этого часа?» и записывает ответы в `log.csv` (открывается в Excel).

## Запуск

1. В Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. Положите токен в файл `token.txt` в этой папке (одна строка).
3. Запустите:

```bash
python bot.py
```

Бот работает, пока открыто окно с ним. Никаких библиотек ставить не нужно.

## Команды

- `/now` — сразу задать вопрос, дальше спрашивать каждый час
- `/stop` — остановить
- `/today` — показать записи за сегодня

Любое обычное сообщение записывается как ответ.
